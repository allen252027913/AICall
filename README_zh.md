# 本地 AI 通话 Android Demo

[English](README.md) | [中文](README_zh.md)

这是一个独立的 arm64 Android 技术 Demo，用来验证“语音通话 + 屏幕共享 + 本地理解 + 无障碍操作”链路。它通过用户可感知的前台服务维持通话，使用 sherpa-onnx 做端侧流式中文 ASR，使用 PP-OCRv5 做端侧 OCR，并支持画中画、图文历史、通用无障碍口令和京东演示流程。

这不是豆包客户端复刻。前台服务、常驻通知和有时限的局部 WakeLock 只能提高活跃会话的连续性，不能让进程“永不被杀”；用户强停、系统或厂商回收、锁屏策略、投屏授权撤销都可能终止能力。

## 已实现能力

- 微信当前小程序／公众号长截图：按钮或“长截图”语音触发，从当前位置自动滚动截图到底、重叠匹配，输出 Bitmap、私有 PNG 和相册原图。接入方式、开源库调研与限制见 [微信长截图说明](docs/WECHAT_LONG_SCREENSHOT.md)。
- 16 kHz 连续流式中文 ASR，使用 sherpa-onnx endpoint 判断一句话结束。
- 命中意图后立即播报确认语，操作完成后只回传一次与当前 token 匹配的结果。
- TTS 播报期间只有规范化后完全等于 `先停一下` 的语音能中断；其他语音不会打断当前轮次。
- 通过系统 MediaProjection 弹窗显式授权；按需截取整屏当前帧，失败最多尝试三次。
- 本地 PP-OCRv5、通话页当前关键帧/OCR 展示，以及基于无障碍窗口事件的来源包名/类名推断。
- 本机私有图文历史 Feed：成功且非空的 OCR 截图以 JPEG + 文本保存，最新在前，最多 50 条。
- 可选画中画：首张图前为紧凑文字模式，首张图后按帧宽高比切换图文模式；通话或投屏结束时立即关闭画中画并隐藏缓存帧。
- 可选“听到公放声音”声学输入模式，以及通用无障碍滑动/点击。
- 语音触发京东演示流程：`我的 → 更多 → 一键领取`，只有两个明确限定的坐标兜底点。
- 保留可注入的商品识别请求、编码和响应解析契约；独立版默认明确返回不可用，不进行网络请求。

生产 Manifest 声明 `INTERNET`，用于长截图合图后的联网识别；不申请 `ACCESS_NETWORK_STATE`。

## 构建与运行

环境要求：JDK 21、compile SDK 36.1、NDK 28.1、CMake 3.22+，以及 Android 8.0/API 26 及以上的 arm64-v8a 真机。

```bash
./gradlew testDebugUnitTest
./gradlew lintDebug
./gradlew assembleDebug
```

APK 输出到 `app/build/outputs/apk/debug/app-debug.apk`。工程内置 ASR/OCR 模型和原生推理库，APK 体积较大，并且只打包 `arm64-v8a`。

真机使用顺序：

1. 打开应用，点击开始通话时允许麦克风权限；Android 13+ 还可能请求通知权限。
2. 点击“共享屏幕”，在系统 MediaProjection 弹窗中授权。每个新的投屏会话都需要新的系统授权。
3. 如果需要跨 App 控制或来源应用推断，从通话页打开无障碍设置，手动启用“本地 AI 通话操作”。
4. 在通话和屏幕共享均开启时离开应用；只有画中画开关开启时才会尝试进入画中画。
5. 可从应用或常驻通知结束通话。

在“查看识别记录”页面，每条记录右上方提供“删除”按钮。确认后会删除该条截图和识别文字，列表立即刷新；取消则保留记录。

点击记录中的图片可全屏查看，支持双指缩放（1–5 倍）和拖动。长按缩略图或大图，选择“保存到相册”，会将完整原图复制到本地相册“识别记录”，不受当前缩放影响，也不会删除原记录。关闭大图可回到原列表位置；保存结果通过提示显示。Android 8–9 首次保存需要允许存储权限，Android 10 及以上无需相册读取权限。

首页顶部“设置”可填写“微信商品采集次数”（默认 10，范围 1–50），保存后下次采集生效，重启仍保留。点击“微信商品关键帧”进入商品详情后，每轮静默 OCR 并保存到识别记录，保存成功才快速上滑一页，等待 1 秒后进行下一轮；最后一轮也滑动。保存或滑动失败会停止；结束通话、停止共享或离开微信会取消后续采集。识别记录最多保留最近 50 条。

打开本应用首页时会在后台预加载 CPU OCR 模型，不需要先开始通话或授权共享屏幕。识别复用进程内同一实例；加载中会等待已有初始化，加载失败可在下次使用时重试。结束通话不会销毁模型，进程退出后由系统回收其内存；重新启动进程会再次预加载。此优化省去首次识别时的模型加载等待，不改变截图、OCR 运算或页面刷新所需时间。`LocalCallOcr` 日志记录初始化耗时与识别获取实例的等待时间。

拒绝麦克风/通知权限、取消投屏授权或系统撤销投屏时，通话页会显示明确提示，并提供重试或进入系统设置的操作。通知权限只影响通知可见性，不是“保活权限”。

## 支持的语音口令

| 类型 | 示例 | 实际行为 |
|---|---|---|
| 查看屏幕 | `帮我看看当前屏幕`、`屏幕上有什么` | 获取一张新帧、本地 OCR、展示并播报；仅成功且 OCR 非空时写入缓存。 |
| 查看商品 | `帮我看一下这个商品` | 获取并编码当前帧后调用注入网关；独立版默认播报“独立版未配置商品识别服务”。 |
| 停止播报 | `先停一下` | 当前确认语或结果语的唯一中断口令。 |
| 滑动 | `下一页`、`上一页`、`向上滑`、`向下滑`、`向左滑`、`向右滑` | 通过无障碍发送归一化屏幕手势。 |
| 第 N 项 | `第一个`、`第3个列表项` | 按 1 开始查找具有集合元数据或列表容器的条目并点击。 |
| 文本控件 | `点下关注按钮`、`点击更多` | 匹配文本/内容描述，点击节点或最近的可点击祖先。 |
| 京东演示 | `去京东打卡` | 打开京东并尝试执行 `我的 → 更多 → 一键领取`。 |

通用无障碍指令没有坐标兜底。京东专用流程中，仅“更多”可兜底到物理像素 `[916,475]`，“一键领取”可兜底到 `[500,574]`；坐标受设备分辨率、系统缩放和京东版本影响，必须在目标真机验证。

## 权限与隐私

- 麦克风 PCM 只送给内置 ASR；应用不保存录音。
- 只有用户确认系统 MediaProjection 授权后才能取得屏幕像素；应用按语音需求取帧，不持续运行 OCR。
- 成功且非空的 OCR 结果保存在应用私有 `cacheDir/local_call_history`：JPEG 质量 85、本地索引、最多 50 条。系统可清理缓存，清除应用数据也会删除它。
- 长截图合图成功后会上传合成图片至预发图片识别接口，并以 `zunyu` 打印识别结果。该流程不上传录音、转写、OCR 文本或无障碍节点内容。
- 无障碍是可选的高敏感权限。开启后，本应用可接收其他 App 的窗口包名/类名，并查看、点击对方暴露的无障碍节点；不用时应在系统设置关闭。
- “听到公放声音”仍然使用手机麦克风，只是切换音源策略并关闭回声消除/降噪，让外放声音可能被声学拾取；它不是数字内录或播放捕获。
- 没有活动通话时切换公放输入，只写入本地偏好，不会额外启动并滞留 `VoiceCallService`。

## 已知边界

- OCR 不能像多模态模型一样完整理解照片、视频、图表和复杂布局。
- 来源信息是根据无障碍窗口事件推断的包名/类名，不是可靠的 Android Activity 栈；第三方 App 是否暴露可点击节点也不稳定。
- 取帧前会隐藏画中画并等待合成器稳定，但 Android/厂商合成时序不同，无法保证每张系统合成帧都绝不包含画中画。
- 原有商品指令的默认网关仍不可用；长截图通过独立 HTTPS 客户端识别，工程没有 MTop SDK 或阿里宿主依赖。
- 京东资源 ID、页面时序和固定像素兜底会随版本及显示配置变化。
- MediaProjection、后台前台服务、画中画、音频路由、无障碍和京东流程仍需要 Android/厂商真机矩阵验证。

完整架构、资源所有权和真机清单见 [docs/LOCAL_AI_CALL_TECHNICAL_ANALYSIS.md](docs/LOCAL_AI_CALL_TECHNICAL_ANALYSIS.md)。
